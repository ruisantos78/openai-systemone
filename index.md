# API Reference

Welcome to the **OpenAI.SystemOne** API documentation. Below are the core namespaces and classes provided by the library.

## Namespaces

- **[OpenAI.SystemOne](xref:OpenAI.SystemOne)**: Core client (`SystemOneClient`), questions (`SystemOneChoiceQuestion`, `SystemOneNoulQuestion`, `SystemOneScoreQuestion`), answers, options, and state/content abstractions.
- **[OpenAI](xref:OpenAI)**: Extension methods for `OpenAIClient` (`GetSystemOneClient`).
- **[Microsoft.Extensions.Hosting](xref:Microsoft.Extensions.Hosting)**: .NET Aspire integration extensions (`AddSystemOneClient`, `AddKeyedSystemOneClient`).
